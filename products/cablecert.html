What to provide

  • The contractor’s CSV export (up to 5 MB)
  • Your expected Cable ID list
  • The contractor CSV should include its recorded test limits when available. The paid browser form does not accept a separate expected-limit value.

The free CSV field check can show recognized columns and row count. It does not compare your expected list with the contractor’s results. If you need a limit checked against a separately supplied expected test limit, use the CableCert MCP audit, which accepts that optional value.

What the $19 report includes

A one-project comparison that lists missing and extra IDs, repeated or retest records, explicit failures, test-limit mismatches, and the source file and row for each finding.

$19 USD · one project · access for up to 24 hours
No automatic renewal.

To start, submit the expected IDs and contractor CSV. The account page asks you to sign in and shows the current offer before you choose whether to continue to Stripe.

What it checks

  • Which expected Cable IDs are missing, and which submitted IDs are unexpected
  • Repeated records or possible retests
  • Explicit submitted FAIL results; no PASS is inferred
  • Browser report: recorded test-limit values and source rows from the CSV. MCP audit: optional comparison with an expected test limit you supply.

Data handling and limits

Raw CSV is processed in memory and is not intentionally saved. If you choose the paid browser report, its result is available to reopen for up to 24 hours. Read the CableCert privacy notice before sending project files.

CableCert flags evidence issues; it does not certify cabling, determine standards compliance or safety, or accept contractor work. A qualified reviewer decides whether the project requirements are met.

For software and connected AI tools

CableCert also offers an MCP connection for software and compatible AI clients. The audit is $0.01 USDC per completed call, billed separately from the $19 browser report. Setup and CSV-inspection tools do not include a full project audit.
