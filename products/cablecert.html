What to provide

  • The contractor’s CSV export (up to 5 MB)
  • Your expected Cable ID list
  • The contractor CSV should include its recorded test limits when available. The paid browser form does not accept a separate expected-limit value.

The free CSV field check shows recognized columns and row count; it does not compare your expected list with contractor results. If you need a comparison against a separately supplied expected test limit, the CableCert MCP audit accepts that optional value.

Your three report deliverables

  1. Project Variance Report — expected versus submitted Cable IDs, duplicate or retest records, explicit failures, test-limit differences and source-row references.
  2. Contractor Remediation List — action items organized by Cable ID, with the evidence row that triggered each item.
  3. Downloadable Excel XLSX / PDF — files you can review and share with the contractor or project team.

$19 USD · one report execution · up to 24 hours to reopen · no automatic renewal.

Flow: prepare the expected IDs and contractor CSV → sign in to bind the case to your account → review the $19 offer → choose whether to continue to Stripe Checkout → open and download the report. Payment is not taken before Checkout.

What it checks

  • Which expected Cable IDs are missing, and which submitted IDs are unexpected
  • Repeated records or possible retests
  • Explicit submitted FAIL results; no PASS is inferred
  • Browser report: recorded test-limit values and source rows from the CSV. MCP audit: optional comparison with an expected test limit you supply.
  • Source file and row details for findings

Data handling and limits

Raw CSV is processed in memory and is not intentionally saved. If you choose the paid browser report, its result is available to reopen for up to 24 hours. Read the CableCert privacy notice before sending project files.

CableCert flags evidence issues; it does not certify cabling, determine standards compliance or safety, or accept contractor work. A qualified reviewer decides whether the project requirements are met.

For software and connected AI tools

The CableCert MCP tools support software and compatible AI clients. Automated MCP pay-per-call (x402) is currently disabled, so no $0.01 USDC charge can be made. If it is enabled later, the separate audit price is $0.01 USDC per completed call; check the live payment metadata before use. The $19 browser report is a separate offer.
