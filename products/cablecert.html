CableCert QA

Independent owner-side review of structured-cabling certification closeout evidence. Supply a CSV export and the expected Cable IDs to identify exceptions for human review.

MCP tools & setupCompare all product pricingLive service status (JSON)

Free first step

Use the free MCP service-information and CSV-inspection tools to see detected fields and supported evidence before running an audit. There is no browser-based upload audit; inspection does not produce the full reconciliation.

Input: CSV only, up to 5 MB, plus the owner-supplied expected link inventory.

Paid audit options

  • MCP: $0.01 USDC per completed audit.
  • Shared platform report: $19 USD for one project audit report, redeemable within 24 hours; no auto-renewal. The central site does not currently provide a purchase button for this offer; use the per-call MCP route unless you already have access to the shared platform.

The amount and unit are shown before the paid action.

What it checks

  • Expected versus submitted Cable IDs
  • Missing and unexpected evidence
  • Duplicate and retest lineage
  • Owner-supplied test-limit mismatches
  • Source file and row provenance

Decision boundary

CableCert reports evidence exceptions. It does not certify cabling, determine TIA compliance or safety, or accept contractor work. A qualified human reviewer decides whether the package meets project requirements.

CSV content is processed in memory and is not intentionally persisted by V1. Read the product privacy notice before submitting sensitive evidence.
