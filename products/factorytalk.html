Free first step

Use the free MCP product-status tool to confirm the service and supported workflow before submitting an import file. There is no browser-based CSV audit; the status call does not validate the file.

Supported inputs: FactoryTalk View tag, digital-alarm, and analog-alarm CSV exports.

Paid audit

Commercial MCP: $0.007 USDC per audit_factorytalk_import call. The paid tool returns a payment challenge before running the audit.

No prepaid web package is currently listed. The published payment route is per-call MCP pricing.

What it checks

The preflight validates the supplied CSV against the supported import contract and reports structural or content exceptions that need attention before import.

Decision boundary

This checks file structure and supported import requirements. It does not establish that an HMI runtime, machine, or process is safe or functionally correct.

Submit only the files and data needed for the check. Review the product privacy notice before sending project data.
