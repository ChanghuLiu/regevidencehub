What it checks

The preflight validates the supplied CSV against the supported import contract and reports structural or content exceptions that need attention before import.

Decision boundary

This checks file structure and supported import requirements. It does not establish that an HMI runtime, machine, or process is safe or functionally correct.

Submit only the files and data needed for the check. Review the product privacy notice before sending project data.
