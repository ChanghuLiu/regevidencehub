Free first step

Use the free MCP status and staged-upload tools to check the service and prepare large XML documents. They do not run the compatibility audit. For a paid two-revision report, submit the baseline and candidate XML in the browser form below.

Small files can be supplied in one request; larger files can be sent as ordered chunks and audited after upload.

What it checks

  • Node removal and NodeClass or BrowseName changes
  • Variable DataType and ValueRank changes
  • Structured DataType Definition changes
  • Removed or redirected existing references
  • Additive nodes and references, reported as information

Decision boundary

This is a static release-compatibility preflight. It does not connect to or control an OPC UA server, PLC, machine, or process. A COMPATIBLE result means no modeled breaking condition was found; it does not guarantee every downstream consumer will work.

Submit only the XML needed for the comparison. Review the product privacy notice before sending model files.
