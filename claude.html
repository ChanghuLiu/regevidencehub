Claude connectors

Add RegEvidenceHub to Claude

Connect Claude to regulatory navigation and technical-evidence tools using the branded Server URLs below. The five regulatory connectors are payment-free; technical audit services have separate access and payment boundaries.

Current Claude distribution: these remote MCP endpoints can be added as custom connectors. Public Connectors Directory publication is a separate Anthropic review process.

Step-by-step: add one connector

Start with one product. These steps are for Claude on the web; labels can vary slightly by plan. Free accounts are limited to one custom connector.

  1. Choose a product below. Use the connector name and Server URL shown on that product card. Copy the complete HTTPS URL exactly; do not change its path.
  2. In Claude, open Customize → Connectors, select + Add, then choose Add custom connector.
  3. Enter the suggested connector name and paste the product's Server URL. Select Continue.
  4. Review the authentication settings Claude detects. Follow the product's instructions; do not invent an OAuth ID, password, API key, or request header. If Claude asks for a credential that the product page does not provide, stop and contact support.
  5. Select Add. Open a conversation, use the + menu to open Connectors, and turn on the connector for that conversation.
  6. Send the card's First test prompt. Ask Claude to confirm which connector/tool it used and summarize the result before sending project files or requesting an audit.

What goes into Claude's setup form?

Only a connector name and the exact Server URL, plus any authentication setting Claude requires and the product explicitly documents. You do not paste JSON tool parameters, CSV/XML files, or a task description into this form.

Where do task details go?

After connecting, describe the task in the Claude conversation. Provide only the inputs the product requires, using its supported method and file limits. If Claude has not confirmed that it received the required input, do not assume an audit was run.

Payment boundary: adding a connector does not itself buy anything. Some technical audit calls have a separate price or payment requirement. Review the product details before requesting an audit; do not assume Claude's connector setup completes an x402 payment.

For Claude's current screens and account-specific options, see the official Claude custom connector guide. If the Add option is missing, a Team or Enterprise workspace policy may control connector access.

Connection troubleshooting

Claude cannot connect

Copy the full HTTPS Server URL again, including its path. Do not remove /mcp or /ai/mcp. Check the official Claude guide for current setup screens and network requirements.

The connector is added, but Claude does not use it

Open the conversation's + menu, choose Connectors, and turn on the connector. Then run the product card's First test prompt in that conversation.

Claude asks for an unexpected credential

Stop and check the product details or contact support. Do not guess credentials, paste wallet secrets, or add a request header that the product instructions did not give you.

A paid audit fails or asks for payment

Check the product's current price and payment requirements before trying again. A successful connection does not mean a paid audit can be settled from Claude; do not repeatedly retry a paid call.

Public directory: adding a custom connector does not publish it in Anthropic’s directory. Publishers on Pro, Max, Team or Enterprise can submit through the official developer portal.
