Claude connectors

Add RegEvidenceHub to Claude

Install any of the five public, payment-free regulatory navigation and preflight connectors as Claude custom connectors using their branded HTTPS MCP endpoints.

Current Claude distribution: these remote MCP endpoints can be added as custom connectors. Public Connectors Directory publication is a separate Anthropic review process.

Install on an individual Claude account

  1. Open Customize → Connectors.
  2. Select +, then Add custom connector.
  3. Enter the suggested connector name below and paste its Server URL.
  4. Add the connector, enable it for a conversation, and run the first test prompt.

Claude supports remote custom connectors on Free, Pro, Max, Team, and Enterprise plans. Free accounts are limited to one custom connector.
