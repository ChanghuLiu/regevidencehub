Grok custom connectors

Add RegEvidenceHub to Grok

Install any of the four public, payment-free regulatory navigation and preflight connectors in your Grok account using their branded HTTPS MCP endpoints.

Current Grok distribution: custom connectors must be added manually. They are account-level connections and are not currently searchable in Grok's public connector catalogue.

Install a connector

  1. In Grok, open Connectors and select New Connector.
  2. Choose Custom.
  3. Enter the suggested name, paste the matching Server URL below, and select Add Connector.
