What this check covers

CableCert compares the supplied CSV with the expected Cable IDs. It can flag missing and unexpected IDs, repeated or retest records, explicit failed results, owner-supplied test-limit mismatches, and the source file and row for findings.

Input and retention

The browser report accepts CSV files up to 5 MB and the owner’s expected ID list. Raw CSV is processed in memory and is not intentionally saved. If a customer chooses the paid browser report, the report result is kept available for up to 24 hours to reopen the case.

Limits

This example uses a synthetic CSV, not a PDF. CableCert does not certify installation, determine standards compliance or safety, or accept contractor work. It flags evidence; it does not decide whether a repeated row is a valid retest or whether the project is accepted.
